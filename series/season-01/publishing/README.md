# Hardstart Films — Thumbnails, títulos, descrições e tags

Pacote dos dez vídeos: uma capa PNG, um título, uma descrição completa e tags em inglês por episódio. As capas são ilustrações originais geradas para a série; os arquivos PNG originais foram copiados sem recorte ou recompressão. Todas têm formato horizontal próximo de 16:9, resolução 1672×941 e menos de 2 MB.

- [Todos os textos prontos para copiar](ALL-METADATA.md)
- [Planilha CSV para Excel](metadata.csv) — UTF-8, separador ponto e vírgula.
- [Metadados estruturados em JSON](metadata-en.json)
- [Conferência de tamanho e limites](validation.json)

Títulos com até 100 caracteres, descrições com até 5.000 e campo de tags com até 500. As tags correspondem ao conteúdo real de cada filme. Não há previsão de CTR, promessa de viralização ou pesquisa de tendências em tempo real. Textos e imagens estão preparados para revisão; o pacote não publica nada no YouTube.
